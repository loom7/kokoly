# ADR-0014: ONNX Runtime 1.28.0 statt 1.23.2

**Status:** angenommen (24.08.2026) — ersetzt den ORT-Teil von ADR-0008
**Kontext-Dokument:** [PROJEKTPLAN.md](../../PROJEKTPLAN.md), M0-Prüfstein

## Entscheidung

onnxruntime-android wird auf **1.28.0** gepinnt.

## Begründung

1.23.2 (die Erstwahl aus der Recherche: erste 16-KB-Page-kompatible Version,
kleinste Bibliothek) stürzt auf dem Zielgerät SM-F971B (SM8850) beim ersten
Modell-Run mit **SIGILL (ILL_ILLOPC) in libonnxruntime.so** ab — reproduziert
in zwei Läufen, Absturzadresse im Bibliothekscode, nicht im JNI. Das Muster
entspricht einer Instruktions-Dispatch-Falle auf dem sehr neuen SoC
(Befähigungserkennung wählt einen Pfad, den der Kernel dem Prozess nicht
erlaubt). 1.28.0 ist die im Nova-Projekt auf **genau diesem Gerät** im
Dauerbetrieb bewiesene Version; mit ihr läuft derselbe Test fehlerfrei durch
(RTF 0,54–0,81, Session-Laden 0,80 s).

## Verworfene Alternativen

Bei 1.23.2 bleiben und den Dispatch umkonfigurieren: ORT bietet dafür keine
öffentliche Option. Ältere Versionen (&lt; 1.23): verlieren 16-KB-Pages.
Bibliotheksgröße von 1.28.0 (~32 MiB arm64) wird als Preis akzeptiert und in
M2a im APK-Budget ausgewiesen.
